## 范围与剩余限制

四个修复版 APK 已使用备份中的原签名构建，并通过 APK Signature Scheme v2/v3、ZIP 对齐、题库/图片资源完整性和 SHA-256 检查。仓库校验还会逐文件比较 APK 内嵌 Web 资源与源码，防止发布旧资源包。尚未在 Android 真机或模拟器跑通安装和界面交互；安装后仍建议先检查政治配图与数学 2026 年题图。
