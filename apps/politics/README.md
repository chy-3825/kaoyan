## 文件

- [questions.jsonl](data/questions.jsonl)：应用可直接导入的逐题数据。
- [manifest.json](sources/manifest.json)：来源、年份、许可和核对记录。
- [summary.json](data/summary.json)：题目数量汇总。
- [preanalysis_audit.json](data/preanalysis_audit.json)：自动预解析覆盖情况与需逐题核验数量。
- `sources/raw/`：真题资料包、2024 年试卷与参考答案，以及 C-Eval、CMMLU 的题源文件。
- `scripts/build_bank.py`：抽取、归一化并校验题库的脚本。

每道题有稳定 ID、题干、A—D 选项、答案、解析、单/多选类型、考点标签 `topicTag`、真题或拓展题标记、年份、来源链接和来源许可。495 道保留来源解析；其余 1,005 道有离线生成内容，其中 189 道命中知识点说明规则，816 道为待补逐项辨析的答案提示。数量和课程分布见 `data/preanalysis_audit.json`。拓展题年份留空，题源主题和原始 ID 保存在 `sourceTopic`、`sourceId` 中。

考点标签使用课程全名：马克思主义基本原理、思想道德与法治、毛泽东思想和中国特色社会主义理论体系概论、中国近现代史纲要、习近平新时代中国特色社会主义思想概论。拓展题按题源学科和题目内容归类；历年真题依据题目内容和对应试卷学科板块标注。

## 来源与核对

- 2009 年真题来自中国教育在线公布的原题与答案解析分页；文都也提供了该年试题 PDF，可用于对照。
- 2010—2023 年来自环球青藤提供的真题解析资料包；2025、2026 年来自其 2020—2026 年资料包。两包在 2020—2023 年有重叠，导入时每年只保留一份。
- 2024 年题目使用郑州工商学院网站发布的试卷 PDF。该 PDF 的文字层有少数可确认 OCR 错字，已订正“檀香山”“大革命”“宣布”等词。
- 2024 年答案采用新东方公布的完整选择题答案表，并与中国考研网答案表交叉核对。另一份启航答案 PDF 的第 23 题以后答案与两份完整答案表不一致，所以不用于这些题的答案。
- 拓展练习来自 [C-Eval 数据集](https://huggingface.co/datasets/ceval/ceval-exam)，固定在提交 `617524a00b307ff6f9933702f724131fe12ca7ce` 的 `test` split。来源许可为 **CC BY-NC-SA 4.0**；题库保留了归属和许可信息。C-Eval 条目不属于考研真题，部分题目没有解析。
- 新增 500 道拓展题取自 [CMMLU 数据集](https://github.com/haonan-li/CMMLU)，固定在提交 `d6e7b716d8ac694f38969a6c0407437d1fded799` 的 `test` split。按马克思主义理论、法律与道德基础、中国历史、高中政治、中国外交政策选取，并按单题内容归入五门课程；它们是拓展题，不是考研真题。许可为 **CC BY-NC-SA 4.0**，归属、文件哈希和选择数量记录在题库资料中。抽查发现 CMMLU 的马克思主义理论第 0 题答案键与定义相反，已按定义订正为 A，并记入来源清单。
- 缺少解析的题目会标明是“离线预解析”还是“答案提示”；答案提示没有逐项分析，不应当作完整解析。所有自动生成内容都应结合教材、可靠来源或 DeepSeek 复核。

APK 1.6.0 加入全库详细解析批处理，对全部 1,500 题逐题调用用户配置的 DeepSeek，并把原有解析作为核对材料。每条成功结果都会按题目 ID 保存在本机，重新打开 APK 后可离线查看；中断后再次启动会跳过已完成题目。批处理使用个人 API 额度，需在 App 的“设置 → 全库详细解析”中主动启动。解析要求覆盖考点、题干、A—D 逐项理由、可核实的原文依据和易错点；不能确认的引文须标为未核实，不得编造出处。

历年真题中的时政题按原考试年份保留，不能当作 2027 年时政知识的现行答案。拓展题没有逐题年份，且可能引用旧政策或旧表述；适合基础巩固，题型和难度不等同于考研政治真题。

## 重建数据

需要 Python、`pdftotext`、网络连接和 `pyarrow`、`requests`：

```sh
python3 -m pip install -r requirements.txt
python3 scripts/build_bank.py
```

重建脚本会读取本地 PDF/Parquet，并重新读取中国教育在线的 2009 年真题分页；随后为每题标注考点标签并更新应用题库。

只刷新离线解析并更新覆盖报告可运行 `python3 scripts/refresh_preanalysis.py`。
