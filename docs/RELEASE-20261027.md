# 研习系列 · 2026-10-27

提供四个独立 Android App：研习高数 1.3.0、研习线代 1.3.0、研习概率 1.3.0、研习政治 1.7.0。适用于 Android 8.0 及以上。

不再提供研习数学总库 App；原题源仅保留作维护资料。

- 数学仅保留真题，相同题目合并并保留试卷出处。
- 题目展示原卷图片，支持点击放大；复制题目使用文字版。
- 数学收藏夹、绿／红描边自评按钮及每题文字解析或原卷答案图。
- 四个 App 同步界面风格、线条图标与底部工具栏。

附件包含四个 APK 和 SHA256SUMS，源码可使用下方 Source code 下载或查看仓库。签名私钥不公开。第三方素材的来源与权利说明见仓库 README。
