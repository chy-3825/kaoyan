# 研习高数

独立的 Android 考研高等数学练习软件，离线收录题目、答案和可用的原题/解析图片。本 App 合并收录数学一、二、三中的全部高等数学题。目录按教材知识顺序排列，不按考试类别分开；题目仍保留考试类别、年份、题号和补充练习来源标记。

## 题库

- 共 925 题：773 道历年题、152 道专题补充练习。
- 题型包括 329 道选择题、194 道填空题和 402 道解答题。
- 题目顺序按章节、考点编排；进入考点后可按年份查看。选择、填空、解答题可筛选。数学一、二、三只显示为题源信息。
- 章节顺序：
- 函数、极限与连续（129 题）
- 一元函数微分学（234 题）
- 一元函数积分学（191 题）
- 常微分方程与差分方程（87 题）
- 向量代数与空间解析几何（1 题）
- 多元函数微分学（119 题）
- 多元函数积分学（116 题）
- 无穷级数（48 题）
- 高数将原题库中混合标注的多元函数微积分题按考点拆为“多元函数微分学”和“多元函数积分学”；概率论合并同义章节标签，保持考点归属。

## 学习功能

- 选择题自动核对；填空题与解答题可查看参考答案后自我评定。
- 解答题可主动加入错题本；主动收录不计答错次数，也可以撤销。
- 本机保存进度、错题、草稿和解析缓存。设置中可导入、导出学习记录备份；备份不含 DeepSeek API Key。
- 可选填个人 DeepSeek API Key 获取逐步解析；不配置也能离线训练和查看原答案。
- 支持题目图和答案图放大，以及题目分享。

## 构建 APK

需要 JDK 17、Android SDK build tools 36，以及 `YANXI_ANDROID_SDK` 环境变量所指的 SDK 路径（默认 `~/.cache/yanxi-android`）。

```sh
python3 scripts/build_bank.py
python3 android/build.py
```

APK 和 SHA-256 文件生成在项目根目录。首次构建会在 `android/signing/` 创建本 App 专用签名密钥。

## 来源与使用

题目数据保留每题原有来源字段。历年题目索引、题图和参考答案图片包含 [`lx-ruc/kaoyanshuxue`](https://github.com/lx-ruc/kaoyanshuxue) 的公开整理资料；2026 年题图来源地址保存在题目数据字段中。专题补充练习不标为历年真题。部分来源未明确图片再发行授权，因此当前 APK 适合个人本地备考；公开发布或商业分发前应取得相应授权。

本目录可使用现有题库直接构建 APK；无需为了打包先重新生成题库。详见[仓库构建说明](../../docs/BUILD.md)。
