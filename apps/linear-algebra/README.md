# 研习线代

独立的 Android 考研线性代数专题练习软件。题库不按数学一、二、三拆分，目录按教材章节和考点组织；每道题仍标注来源考试、年份和题号，方便回看原卷。

## 题库与目录

- 收录数学总库中的全部线性代数题，共 318 题：270 道 2009–2026 年历年真题和 48 道专题补充练习。
- 数学一、二、三各 106 题，其中 90 道真题、16 道补充练习。考试类别仅用于显示题源，不作为目录或筛选入口。
- 章节顺序：行列式、矩阵、向量、线性方程组、矩阵的特征值与特征向量、二次型。
- 每章先列考点，再列题目；考点内部按年份、考试类别和题号排序。选择题、填空题和解答题可在考点题目列表中筛选。
- 真题题源显示为“年份 · 题号”，数一、数二、数三另行标注；补充题只显示“专题补充”，不显示年份和题号。
- 补充练习有离线参考答案与解题要点，不标作历年真题。

## 学习功能

- 选择题自动核对；填空题与解答题可查看参考答案后自我评定。
- 解答题可主动加入错题本；主动收录不计作答错次数，可以撤销。答错记录与主动收录记录分别显示。
- 学习进度、错题、作答草稿和解析缓存保存在本机。设置中可以导出或导入备份；备份不包含 DeepSeek API Key。
- 可配置个人 DeepSeek API Key 生成解析；不配置也能离线训练、查看题目已有答案。
- 支持原题图放大、答案图放大和题目分享。

## 构建 APK

需要 JDK 17、Android SDK build tools 36，以及 `YANXI_ANDROID_SDK` 环境变量所指的 SDK 路径（默认 `~/.cache/yanxi-android`）。

```sh
python3 scripts/build_bank.py
python3 android/build.py
```

APK 会生成在项目根目录。首次构建会在 `android/signing/` 创建本 App 专用签名密钥。
