# 研习政治 Android

当前版本 1.6.0（versionCode 9），包名 `com.yanxi.politics`。Android 8.0 及以上，使用系统 WebView。

首页突出续练入口，删去重复题库概况和说明文字。课程目录按五门课程组织；进入课程后可按未答、错题筛选并跳转。训练页显示课程简称和进度；历年真题只显示“年份 · 题号”，补充题不显示出处。底部固定上一题和下一题；单选点击后判分，多选确认后判分，作答状态会保留。错题可按课程筛选，需手动标记已掌握。设置页可调整字号、配置 DeepSeek API、导出或恢复学习记录。

题库内置 1,500 题。495 题沿用来源解析；其余 1,005 题有规则生成的答案提示或单一考点说明，需要补充完整的逐项辨析。数据报告在 `../data/preanalysis_audit.json`。可逐题生成 DeepSeek 解析，也可在“设置 → 全库详细解析”统一生成全部 1,500 题的解析，并把已有解析作为核对材料。批处理逐题保存进度、失败后可重试；完成的解析会缓存在本机，覆盖安装后可离线查看。复制题目包含课程、真题出处（如有）、题干及全部选项，不包含答案。API Key 在手机端通过 Android Keystore 的 AES-GCM 加密保存在私有存储，不进入学习记录备份，不写入 APK。模型默认为 `deepseek-flash`，可在设置中修改。批处理和逐题解析都使用个人账户额度。

学习记录沿用旧版 `yanxi-politics-v1` 数据，覆盖安装保留记录；设置页可通过系统文件选择器导出和恢复进度、答题结果、错题及字号。备份不含 API Key，密钥仍保存在本机。卸载或清除应用数据会删除记录和密钥。网页版记录与 APK 独立。仅供个人备考，题库来源和授权记录在上级 `sources/manifest.json`。

## 构建

JDK 17、Android SDK platform 36、build-tools 36.0.0。执行 `python3 build.py`，默认工具路径 `~/.cache/yanxi-android`，可通过 `YANXI_ANDROID_SDK` 指定同布局目录。网页源文件在 `web/`；标签同步写入题库和 Android 应用。

`signing/` 是私有签名密钥，不要公开或删除。更新保持包名和密钥不变、递增版本号。产物位于上级目录。

## 修复及验证

1.0.1 修复窗口尚未建立时访问系统栏控制器造成的启动空指针崩溃。该问题已在 Android 14 模拟器复现，修复版通过连续启动、离线作答、错题复习及覆盖安装保留记录检查。

`verification/` 保存验证脚本、日志和截图。测试脚本仅对专用 `yanxi-smoke` 模拟器运行，部分脚本会卸载该模拟器内的测试 App，禁止用于个人手机。

1.3.0 重做首页、课程目录、题目目录和训练页；增加题目跳转、作答状态标记、字号设置，并完善返回导航。课程分类沿用全名标签。

1.4.0 将题库扩至 1,500 题，为每题补齐解析或离线预解析。

1.5.0 精简核心界面；统一真题出处格式；增加错题课程筛选和手动掌握状态；支持学习记录导入导出；缓存 DeepSeek 解析；标出缺少逐项辨析的答案提示，并在解析页折叠题源信息。

1.6.0 明确逐题解析结构；增加可暂停、续跑的 1,500 题批量解析，并逐题保存结果；解析页分开展示原有解析与 AI 详细解析，保留换行和标题。
