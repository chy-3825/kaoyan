# 研习政治

首页保留续练、课程目录和错题本入口；目录可按题目状态筛选。真题来源显示为“年份 · 题号”，补充题不显示出处。学习记录保存在当前浏览器 localStorage，不跨设备同步，可在安卓端导出和恢复。

直接打开 dist/index.html 即可本地使用，无需安装依赖。也可使用任意静态 HTTP 服务。

多选需确认后判分；错题需要手动标记已掌握，不会因答对一次自动移出。题目字号可在设置中调整；网页版支持复制题目和导入、导出学习记录。DeepSeek API 调用需在 Android APK 中配置，成功生成的解析会缓存。历史真题应按当年背景作答。部分自动内容仅是答案提示，题库审计记录位于上一级目录；题源与授权信息可在解析中展开查看。

Android APK 1.6.0 另提供全库详细解析批处理：使用本人配置的 DeepSeek API 额度，为 1,500 道题统一生成逐项解析，并把题库已有解析作为核对材料；每题包含考点定位、题干分析、A—D 逐项理由、可核实的原文依据和易错提醒。结果保存在 APK 本机，批处理可中断后续跑；网页版不包含此批量入口。
